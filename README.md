## 🚀 Featured Projects

### 🔐 [Oxla: Multimodal Voice AI Executive Assistant](https://github.com/karthik15-art/Oxla_agent)
A real-time voice assistant with biometric-gated executive mode.
- Real-time bidirectional voice streaming with **LiveKit Agents**, **WebRTC** and the **Gemini Realtime API**
- **53 custom tools** for automated OS tasks
- Dual biometric verification (OpenCV LBPH face recognition + voice matching) and a **3-layer guardrail system** against prompt injection (100% test pass rate)
- Long-term memory protected with **Fernet** encryption

`Python` `LiveKit` `Gemini Realtime API` `OpenCV` `WebRTC`

### 📰 [Fake News Detector](https://github.com/karthik15-art/Fake-News-Detector)
An NLP web app that classifies a news article as Real or Fake, with a confidence score.
- Logistic Regression trained on **44,898 articles**, reaching **97.76% accuracy**
- Found and fixed a data leakage issue where the model relied on publisher tags instead of article text
- Deployed with **Streamlit**

`Python` `Scikit-learn` `NLP` `Pandas` `Streamlit`

### 🩺 [Disease Symptom Predictor](https://github.com/karthik15-art/symptom-based-disease-prediction)
A web app that predicts likely diseases from selected symptoms.
- Random Forest trained on **4,920 patient records** across **131 symptoms** and **41 diseases**
- Shows the predicted condition with confidence score, description and precautions

`Python` `Scikit-learn` `Random Forest` `Streamlit`
